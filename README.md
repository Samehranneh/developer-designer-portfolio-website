# Developer & Designer Portfolio Website

A multi-section portfolio website built for a client team of a programmer and a graphic designer.

## Sections

- Hero with call-to-action and CV download
- About, with stats (clients, projects, awards)
- Services (UI/UX, web design, app design)
- Portfolio gallery
- Testimonials
- Blog
- Contact
- A separate components page (buttons, forms, dropdowns, tags) used as a style guide

## Stack

HTML5, SCSS, Bootstrap, jQuery, Themify icons. Gulp compiles SCSS and serves the site locally.

## Run locally

```bash
npm install
npx gulp
```

Or open `index.html` directly in a browser.
